Referência de Stack Tecnológica
Este arquivo serve como referência de contexto para a IA (Agentes) durante a criação e manutenção de aplicações.
Tecnologias Definidas
* Runtime/pkg manager: Bun
* Linguagem: TypeScript
* Frontend: TanStack Start (React 19) + Vite
* Estilo/UI: Tailwind v4 + shadcn/ui
* Backend: Hono (rotas /api)
* Banco de dados: PostgreSQL 16 + Drizzle ORM
* Auth: Better Auth (plugins organization + admin)
* Testes: Vitest + Playwright
Diretrizes para a IA
Ao gerar código, estruturar projetos ou planejar arquiteturas, siga estritamente as tecnologias listadas acima. Priorize a segurança de tipagem (type-safety) de ponta a ponta usando TypeScript. Utilize Bun como ambiente de execução e gerenciador de pacotes para máxima performance.
